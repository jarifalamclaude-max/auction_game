# ⚽ Football Auction Game (অনলাইন)

বন্ধুরা **যার যার বাসা থেকে** একসাথে খেলার ফুটবল প্লেয়ার অকশন গেম।

- একজন **মাস্টার** অকশন চালায়: প্লেয়ার কল করে, SOLD / Unsold করে। চাইলে মাস্টার নিজেও একটা টিম নিয়ে খেলতে পারে।
- বাকি বন্ধুরা লিংক খুলে নিজের **ফোন/ল্যাপটপ থেকে** নিজের টিমের হয়ে বিড করে।
- প্লেয়ার কল করলে সবার স্ক্রিনে একসাথে তার **FIFA-স্টাইল কার্ড + ছবি** উল্টে বের হয়।

> পুরো গেম একটাই ফাইল: **`index.html`**। কোনো সার্ভার, অ্যাকাউন্ট বা টাকা লাগবে না।
> সবার ফোনের মধ্যে কানেকশন হয় একটা **ফ্রি পাবলিক সার্ভার** (MQTT) দিয়ে, এটা নিজে থেকেই হয়।

## 🌐 ধাপ ১: গেমটা ফ্রি ওয়েবসাইটে তোলো (একবারই করতে হবে, ৫ মিনিট)

বাসা থেকে সবাইকে খেলাতে হলে গেমের একটা **লিংক** লাগবে। GitHub Pages-এ ফ্রিতে হয়ে যায়।

1. [github.com](https://github.com)-এ লগইন করো। যে অ্যাকাউন্টের repo, সেই অ্যাকাউন্ট দিয়ে লগইন করতে হবে। এই repo **Iftakhar-uz-zaman** অ্যাকাউন্টের।
2. **FootballAuctionGame** repo খোলো → **Add file** → **Upload files**।
3. `index.html`, `players.csv`, `README.md` টেনে ছেড়ে দাও → নিচে সবুজ **Commit changes**।
4. উপরে **Settings** → বাম পাশে **Pages**।
5. **Source** = **Deploy from a branch**, **Branch** = `main`, ফোল্ডার = `/ (root)` → **Save**।
6. ১–২ মিনিট পর পেজ refresh করলে লিংক আসবে:

   👉 **`https://iftakhar-uz-zaman.github.io/FootballAuctionGame/`**

এটাই তোমাদের গেমের ফ্রি ওয়েবসাইট। পরে আপডেট করতে হলে নতুন `index.html` একইভাবে আপলোড করলেই হবে।

## 🎙 ধাপ ২: মাস্টার অকশন খোলে

1. মাস্টার ল্যাপটপে (বা ফোনে) গেমের লিংক খোলে।
2. **Be the master** অংশের ফর্মে লেখো:
   - কয়টা টিম আর টিমের নাম (যেমন বন্ধুদের নামে), প্রতি টিমের বাজেট
   - প্রতি টিমে সর্বোচ্চ কতজন, বিড কত করে বাড়বে, **টাইমার** (ডিফল্ট ২০ সেকেন্ড: শেষ বিডের পর ২০ সেকেন্ড কেউ বিড না করলে নিজে নিজেই SOLD)
3. **Start auction ▶** চাপো।
4. একটা **Room** উইন্ডো আসবে। সেখানে **রুম কোড** (যেমন `KXPTA0`) আর **ইনভাইট লিংক** থাকবে।
   - **Copy** বা **WhatsApp** চেপে লিংকটা বন্ধুদের গ্রুপে পাঠাও।
5. মাস্টারও খেলতে চাইলে নিজের টিমের পাশে **"I play this team"** চাপো।

> ⚠️ **মাস্টারের পেজটা পুরো অকশনের সময় খোলা রাখতে হবে।** মাস্টারের ব্রাউজারই গেম চালায়। ফোনে মাস্টার হলে স্ক্রিন যেন বন্ধ না হয়ে যায়, আর ট্যাব বদলাবে না। ল্যাপটপ হলে সবচেয়ে ভালো।

## 🙋 ধাপ ৩: বন্ধুরা জয়েন করে

1. বন্ধু WhatsApp-এ পাওয়া লিংকে ক্লিক করে।
   (অথবা গেমের লিংক খুলে **"Join a friend's auction"**-এ রুম কোড লিখে **Join** চাপে।)
2. **নিজের নাম** লেখে → **নিজের টিম** বেছে নেয়।
3. ব্যস! প্লেয়ার কল হলে কার্ড আসবে আর বড় সবুজ **BID** বাটন আসবে।
   - **BID** চাপলে সর্বনিম্ন পরের অ্যামাউন্টে বিড হয়।
   - **+5 / +10 / +25** চেপে লাফিয়ে বড় বিড দেওয়া যায়।
   - সবার আগে যার বিড মাস্টারের কাছে পৌঁছাবে, সেটাই গণ্য হবে।
4. শুধু দেখতে চাইলে **"Just watch"**।

## 🎮 মাস্টারের কন্ট্রোল

| কাজ | বাটন / কীবোর্ড |
|---|---|
| পরের প্লেয়ার কল | **Call next player ▶** বা `N` |
| বিক্রি | **🔨 SOLD** বা `S` (টাইমার শেষ হলে নিজেই হয়) |
| কেউ না কিনলে | **✖ Unsold** বা `U` |
| ভুল ঠিক করা | **↶ Undo** বা `Ctrl+Z` |
| কোনো বন্ধুর নেট সমস্যা হলে তার হয়ে বিড | ওই টিমের বাটনে ক্লিক (বা `1`–`9`) |
| টাইমার থামানো | **⏸ Pause** বা `Space` |
| নির্দিষ্ট প্লেয়ারকে আনা | **Players** ট্যাব → প্লেয়ার → **Call for bid now** |

- **Teams** ট্যাবে সবার বাকি টাকা আর কেনা প্লেয়ার দেখা যায়। ✕ চাপলে প্লেয়ার বাদ দিয়ে টাকা ফেরত দেওয়া যায়।
- সব প্লেয়ার শেষ হলে **unsold প্লেয়ারদের আবার অকশন** করা যায়। সব টিম ভরে গেলে অকশন নিজে থেকেই শেষ হয়।
- **Settings** → রেজাল্ট (CSV) ডাউনলোড, ব্যাকআপ।

> 💾 গেম মাস্টারের ব্রাউজারে নিজে নিজে সেভ হয়। পেজ বন্ধ হয়ে গেলে আবার খুললেই আগের জায়গা থেকে চলবে, বন্ধুরাও আবার কানেক্ট হয়ে যাবে।

| মাস্টারের স্ক্রিনে 🔴 **Offline** | নেট চেক করো। তারপর Room → **Try another server**। এতে কোড বদলাবে, নতুন লিংক আবার পাঠাতে হবে। |
| বিড চাপলে "Too late…" | অন্য কেউ আগে বিড করেছে। আবার BID চাপো। |
| ছবি ভুল / নাই | মাস্টার কার্ডের নিচে **📷 Change photo** চাপবে: ছবি আপলোড বা ছবির লিংক দিলে সবাই সেটাই দেখবে। |

## ✏️ প্লেয়ার লিস্ট বদলাতে চাইলে

1. `players.csv` Excel বা Google Sheets-এ খোলো।
2. কলাম: `name, position (GK/DEF/MID/FWD), nationality, club, age, rating, base_price, photo`
   - `rating` দিলে কার্ডে FIFA-র মতো রেটিং দেখাবে (না দিলেও চলবে)
   - `photo`-তে ছবির লিংক দিলে সেই ছবিই দেখাবে
3. **CSV UTF-8** হিসেবে সেভ করো (Excel-এ: Save As → "CSV UTF-8")।
4. গেমের শুরুর পেজে **"📄 Use a different player list (CSV)"** চেপে ফাইলটা দাও।

> নোট: আসল লিস্টে ৮ জন প্লেয়ার দুইবার করে ছিল (Koundé, Cambiaso, Wirtz, Luis Díaz, Malo Gusto, Cherki, Kvaratskhelia, Doué)। প্রত্যেককে একবারই রাখা হয়েছে।

> 🔒 ফ্রি পাবলিক সার্ভার ব্যবহার হয়, তাই রুম কোড জানলে যে কেউ দেখতে পারবে। বন্ধুদের মধ্যে খেলার জন্য এটা সমস্যা না। কোড শুধু বন্ধুদের গ্রুপেই দিও।
